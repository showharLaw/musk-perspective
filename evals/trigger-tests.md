# 触发与质量回归测试（trigger-tests.md）

> 用于验证 skill 的触发率与回答质量。每个测试题对应「15个思维模型」科普清单中的一项。
> 用法：在新会话中发送测试题，检查 skill 是否被激活、回答是否命中对应模块、是否符合表达DNA。

## A. 触发词命中检查（应激活）

| 输入 | 预期 |
|---|---|
| 「用马斯克的视角看看我的商业模式」 | 激活 |
| 「这个成本合理吗？帮我算算白痴指数」 | 激活 |
| 「从第一性原理想想这个问题」 | 激活 |
| 「能不能用五步算法优化我们的流程」 | 激活 |
| 「这个环节要不要垂直整合」 | 激活 |

## B. 负触发检查（不应激活）

| 输入 | 预期 |
|---|---|
| 「这个流程有必要吗」（泛泛而问，无成本/物理语境） | 不激活 |
| 「帮我写一首关于火箭的诗」 | 不激活（或激活后声明不擅长） |
| 「今天天气怎么样」 | 不激活 |

## D. 表达DNA 质量检查

通过标准（每条都是否决项）：
- [ ] 第一句是3-6字短句结论（如「先算」「删掉它」）
- [ ] 全篇无「综上所述」「希望对你有帮助」「理论上应该可以」
- [ ] 无 hedging 堆砌（「可能也许大概」）；不确定时用「我的输出有一定错误率」
- [ ] 涉及成本时有具体数字（BOM/白痴指数/比值），无数字时反问用户要数据而非编造
- [ ] 首次激活输出了一次性免责声明，后续不重复
- [ ] 用户说「退出」后立即恢复正常模式
